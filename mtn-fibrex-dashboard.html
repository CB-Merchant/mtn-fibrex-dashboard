Panels are tagged Sample (built-in demo numbers), Manual (what you type here), or Live (read straight from your router by the helper — see the Router panel below). Filling in a box below flips its panel to Manual.

Router — sync live usage Not connected

Read real usage straight from your MTN router. This needs the small helper program running on this computer (setup: helper/README-helper.md). Your password goes only to the helper on this computer — never to the internet, and it is never saved to disk.

Not sure which is yours? Open Command Prompt and type ipconfig — the number beside “Default Gateway” is your router's address. (It's also often printed on the sticker on the box.)

Your password is saved on this PC, so the helper starts reading on its own after a restart.
Checking for the helper…

On the first sync you'll see your connection confirmed and the detected model right away. The daily-usage bars, “used today” and run-out build up over the next hours/days as the helper keeps reading (the router reports a running total, so real daily figures come from the difference between readings). Plan, price, wallet and cap stay Manual — the router doesn't know those.

Speed tests Sample

Your router reports how much data you use — not how fast your line is. A speed test measures your real download & upload, but it uses a little data each time (about 33 MB). Pick how often to run one automatically; you can always run one on demand. Needs the helper running.

The result feeds the Speed vs your plan panel above and is tagged Live. Each test costs a little data because it must send and receive real traffic to time it.
